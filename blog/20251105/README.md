**Цель** - это результат, который я хочу получить.  
**План** - это набор шагов, что бы добиться этого результата. Т.е. описание того, как пройти их точки А в точку Б, где:
- точка А - текущее состояние;
- точка Б - желаемое состояние.  
  
**Гипотеза** - предположение об окружающем мире, которое можно проверить.

Проверяемое утверждение: "цель - это гипотеза". Возможно имеется в виду, что для достижения цели используются гипотеза(ы)?  
Цель -> гипотеза -> план.

Примеры возможных гипотез:
- мы выбрали лучший способ добиться этого результата?
    - минус: сложно проверяемая
- достижимость указанного результата в заданное время с заданными ресурсами?
    - минус: слишком большая для использования
- эта последовательность шагов, приведет к результату? или более мелкая гипотеза:
    - этот шаг приблизит меня к результату? Выглядит, как самый подходящий вариант использования гипотез для достижения цели.
